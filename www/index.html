salukid // secure_httpd

A hardened, high-performance HTTP server in C serving HTTP/1.1, HTTP/2, and HTTP/3.

Endpoints

  • /healthz — liveness probe
  • /metrics — Prometheus metrics
  • /_hello — sample dlopen module (if loaded)

Test it

$ curl -k --http2 https://localhost:8443/
$ curl -k --http3 https://localhost:8443/
$ curl  http://localhost:8080/metrics
